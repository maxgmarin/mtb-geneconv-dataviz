This page contains an interactive visualization of the core results from our paper, “Gene conversion is a key driver of diversity hotspots in Mycobacterium tuberculosis antigens and virulence-associated loci.”

Manuscript GitHub repo

The table above lists all individual gene conversion events detected across the evolutionary history of a dataset of 151 M. tuberculosis genomes.

Below it is an integrated genome browser (built with Gosling) showing the distribution of all detected putative gene conversion events (N = 324) across the entire Mtb genome.

Selecting an event in the table above will move the genome browser to that region. Conversely, clicking an event block in the genome browser will select and highlight its row in the table.
