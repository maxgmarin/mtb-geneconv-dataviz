TBP22/22CI — Gene-Conversion Event Verification Viewer

Re-sequencing verification for 12 candidate gene-conversion events. For each event, the Verification (target) isolate is expected to carry the recombinant variant and the Control isolate is expected not to. Each report shows the H37Rv region (±10kb flanking) with 8 tracks: H37Rv gene annotation, the H37Rv self-to-self homology map, then the target isolate's Assembly / Long-read / Short-read alignments, then the control isolate's same 3 alignment types. Every report is a fully self-contained, standalone HTML with all track data embedded directly — nothing loads from a remote server.
